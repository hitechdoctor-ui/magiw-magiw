## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Admin

Configure environment variables on the host (never commit secrets). See `/admin` after setting admin credentials.

## Deploy

Production builds with `npm run build` then `npm start`.
